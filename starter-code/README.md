# Starter Code Library

Use this folder to keep reusable project starters in one place.

Suggested pattern:

1. Create one subfolder per starter.
2. Add a short `README.md` with what the starter is for.
3. Keep any prompt notes, screenshots, or setup steps inside that starter folder.
4. Store reusable snippets here, but keep the live app at the project root.

This repo already includes one starter record:

- `triton-nav-mvp/`

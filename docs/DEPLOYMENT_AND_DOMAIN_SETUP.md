## 10. Rollback Procedure

Rollback redirect/canonical app changes:

```bash
git revert <commit-containing-domain-and-homepage-work>
```

Rollback manually before merge:

```bash
git switch main
git branch -D feature/mobile-homepage-and-domain-consolidation
```

Rollback deployed production after merge:

1. Revert the merge commit on `main`.
2. Push `main`.
3. Let Vercel redeploy.
4. Verify both URLs.
5. Do not delete domains or DNS records during rollback unless explicitly approved.
